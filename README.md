# Сайт-приглашение на свидание 💗

Статический адаптивный сайт на HTML, CSS и JavaScript. Работает на GitHub Pages бесплатно.

## Файлы
- `index.html` — разметка и тексты
- `style.css` — оформление и мобильная адаптация
- `script.js` — кнопки, выбор идеи/даты/времени, финальный экран и переход в Telegram

## Как опубликовать через GitHub Pages
1. Войдите на https://github.com/ или создайте аккаунт.
2. Нажмите **New repository**.
3. Назовите репозиторий, например `date-invitation`. Для простоты выберите **Public**.
4. Загрузите `index.html`, `style.css`, `script.js` и `README.md` в корень репозитория (кнопка **Add file → Upload files**).
5. Откройте **Settings → Pages**.
6. В блоке **Build and deployment** выберите **Deploy from a branch**.
7. В качестве Branch выберите `main`, папку `/ (root)`, затем **Save**.
8. Подождите минуту или несколько. Ссылка появится в разделе **Settings → Pages** и будет иметь вид `https://ВАШ-ЛОГИН.github.io/date-invitation/`.

## Как настроить Telegram
### Самый простой вариант — отправка через Telegram Share
По умолчанию сайт открывает Telegram с подготовленным сообщением. Девушка сама выбирает чат и нажимает «Отправить». Это не отправляет ответ тебе автоматически: она должна выбрать твой чат.

Если хочешь, чтобы ссылка сразу открывала чат с тобой, замени обработчик `sendBtn` в `script.js` на такой вариант, указав собственный username Telegram:
```js
const YOUR_TELEGRAM_USERNAME = "ВАШ_USERNAME_БЕЗ_СОБАКИ";
sendBtn.addEventListener("click", () => {
  const p = currentPlan();
  const message = `Привет! 💗 Мой ответ: ДА!\nИдея: ${p.idea}\nДата: ${p.date}\nВремя: ${p.time}${p.note ? `\nКомментарий: ${p.note}` : ""}`;
  window.open(`https://t.me/${YOUR_TELEGRAM_USERNAME}?text=${encodeURIComponent(message)}`, "_blank", "noopener");
});
```
Перед этим удали/замени существующий `sendBtn.addEventListener(...)`, чтобы обработчик не срабатывал дважды. У Telegram поддержка предварительно заполненного текста зависит от клиента; сообщение не отправляется автоматически.

### Вариант с ботом
Обычная ссылка на бота `https://t.me/ИМЯ_БОТА?start=...` передаёт боту параметр запуска, а не произвольное готовое сообщение. Чтобы бот присылал тебе ответы, нужно создать бота через `@BotFather`, разместить обработчик на сервере/облачной функции и хранить токен безопасно. **Не вставляй токен бота в публичный JavaScript-файл** — его увидит любой посетитель сайта.

## Важно
- GitHub Pages — публичный хостинг: любой, у кого есть ссылка, сможет открыть сайт.
- Страница не сохраняет данные на сервере.
- Дата/время — предложение, их можно согласовать позже.
- Кнопка «Нет» остаётся доступной; приглашение не должно давить на человека.
